RL Pro Tracker.

How it works

Last updated 2 September 2026

Every figure on the board comes from a public source, collected automatically every few minutes. This page explains what each column means, and where it stops being reliable.

1. Three sources

  • Ranks and games played — each player’s public Rocket League Tracker profile.
  • Playtime hours — the Steam Web API.
  • Rosters — Liquipedia.

Nothing is collected by logging into anything, and no private data is touched.

2. Why some players have no hours

Steam has two privacy settings, and they break things differently:

  • Private The whole profile is closed. Nothing can be read from outside, playtime included.
  • Hidden The profile stays open but the game details section is switched off. The profile loads fine; the playtime is simply not published.

Either way Steam publishes no playtime, so Total h stays blank instead of being filled with a guess. Ranks come from a different source, which is why a player can show a full set of MMR numbers and no hours at all.

3. Estimated hours

Steam still shows what someone is playing right now, even when it hides how long they have played. So for those profiles the site checks every few minutes and credits the time whenever it finds them in Rocket League.

Those numbers appear in 2wk h with a tilde and a dotted underline. They always undercount: a session that starts and ends between two checks is invisible, and nothing before tracking started is counted. Treat them as a floor. A plain number in that column is Steam’s own figure.

4. Numbers that stop moving

Players sometimes open a profile that used to be closed. When that happens the total playtime is saved, so it stays on the board if they close it again rather than vanishing.

It is frozen at that point: real, but stuck at whatever it read that day until the profile reopens. Those totals carry an asterisk, with the date on hover. The 2-week column is deliberately not carried over, because it covers a rolling fortnight and an old value would look like recent activity.

5. How current it is

Every player is re-checked on the same few-minute cycle, so no row is fresher than another. The timestamp at the top of the board is the last collection. Ranked stats only move when a match ends, and a match plus queue is around seven minutes, so a few minutes old is as live as this gets.

6. Rough edges

This is a new project and still being built, so expect the odd number that looks off. Regions follow each team’s competitive region rather than nationality, so a player living elsewhere still shows their team’s region.

If something looks wrong, the feedback form on the tracker is the fastest way to tell me. Discord works too, at @_198x.
