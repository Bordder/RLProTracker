Privacy & terms

Last updated 2 September 2026

Short version: this site has no accounts, sets no cookies, and asks you for nothing. The only information it ever receives from you is what you deliberately type into the feedback form.

What is collected about you

Nothing, unless you send feedback. There is no sign-up, no cookie banner because there are no cookies, no advertising, and no third-party trackers. The page is static files and public JSON.

Visit counts. Cloudflare Web Analytics counts page views so I can tell whether anyone is using the site. It is cookieless, does not fingerprint you, and cannot follow you to other sites. It records the page URL, referrer, and coarse details like country and browser — never an identity. If you run an ad blocker it is probably blocked already, and the site works exactly the same.

Server logs. Cloudflare keeps short-lived request logs, including IP addresses, as part of serving and protecting any website. I do not export, store, or analyse them.

The feedback form

Whatever you type — the message, and the username if you fill it in — is posted publicly as an issue on the project's GitHub repository, where anyone can read it. Please do not put anything private in it. The username field is optional and free-text; it is not verified and does not have to be your real name.

Your IP address is not stored with the message, and nothing links a submission back to you.

Where the player data comes from

Every number on this site is already public, and is collected without logging into anything:

  • Rosters from Liquipedia, under its open licence.
  • Playtime from the public Steam Web API, which only returns what a player has chosen to make visible. A private profile returns nothing and the site leaves those cells blank rather than guessing.
  • Ranks and games played from public Rocket League tracking pages.

Only players competing in RLCS are listed, and only their competitive activity — nothing personal, nothing about private individuals. If you are one of the players here and want your row removed, send a message through the feedback form and I will remove it.

Terms

This site is provided as-is, for information and curiosity, with no guarantee that any figure is accurate, current, or complete. Sources go down, profiles get hidden, and collection sometimes fails; treat the numbers as an indication rather than a record. Do not rely on them for betting, and do not use them to harass anybody.
